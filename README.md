# 119 LAUNDRY & Dry Cleaning

A modern, high-performance website for **119 LAUNDRY & Dry Cleaning** featuring online pickup scheduling, service calculators, and real-time database persistence powered by Supabase.

## ✨ Features

- **Service Catalog & Pricing**: Interactive price calculator for Wash & Iron, Wash & Fold, and Specialty Dry Cleaning.
- **Doorstep Pickup Booking**: Form for scheduling pickups with time slots, garment weight estimates, and instant WhatsApp confirmation dispatch.
- **Supabase Integration**: Live database persistence storing customer pickup bookings directly in PostgreSQL.
- **VIP Membership Waitlist**: Interactive modal capturing customer membership inquiries.
- **Connectivity Diagnostics**: Built-in test suite (`test-db.html`) for end-to-end database health checks.
- **Responsive Design**: Mobile-first design system with fluid typography and interactive micro-animations.

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, CSS3 (Custom Design System), Vanilla JavaScript (ES6+)
- **Backend / Database**: [Supabase](https://supabase.com) (PostgreSQL with Row Level Security)
- **Third-Party Integrations**: WhatsApp API for instant booking confirmations

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone git@github.com:krishhh-jpg/Krsish-.git
   ```
2. Open `index.html` in your browser or run a local web server:
   ```bash
   python3 -m http.server 3000
   ```
3. Visit `http://localhost:3000` to view the website.
